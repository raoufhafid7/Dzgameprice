## تشغيل ورفع الموقع
1. فك ضغط الملف.
2. ارفع الملفات الثلاثة إلى مستودع GitHub.
3. في Vercel اختر المستودع.
4. Framework Preset: `Other`.
5. Build Command: اتركه فارغًا.
6. Output Directory: اتركه فارغًا، وRoot Directory هو جذر المشروع.
7. اضغط Deploy.

يمكن أيضًا فتح `index.html` مباشرة في المتصفح.

## مهم قبل اعتبار الأسعار حقيقية
الأسعار والعروض داخل هذه النسخة بيانات تجريبية، ولا يتم تحديثها من متاجر الجزائر تلقائيًا. الموقع نفسه يعمل كواجهة أمامية؛ لتحويله إلى مقارنة أسعار حقيقية يلزم إضافة قاعدة بيانات أو لوحة إدارة، وأسعار موثوقة وروابط المتاجر، مع آلية لتحديث الأسعار. لا تعرض البيانات التجريبية على أنها أسعار فعلية.
